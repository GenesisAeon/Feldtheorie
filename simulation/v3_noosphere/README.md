## 🧪 Quick Start

### Run the Hex Lattice Demo

```bash
PYTHONPATH=/path/to/Feldtheorie python simulation/v3_noosphere/spatial/hex_lattice_demo.py
```

This will:
1. Create a 10-radius hexagonal lattice (~300 cells)
2. Spawn 12 agents on habitable terrain
3. Demonstrate pathfinding and movement
4. Calculate territory control (Voronoi diagram)
5. Visualize the lattice as ASCII art

## 🔮 The Vision

**V3 Noosphere** is the foundation for simulating the **full arc of civilization**:

1. **Dawn** — Scattered agents on a hex grid
2. **Settlement** — Agents cluster near resources (proto-cities)
3. **Trade** — Graph networks emerge (economic webs)
4. **Culture** — Memes propagate (shared beliefs)
5. **Golden Age** — High σ_Φ (crystalline stability)
6. **Decline** — Resource depletion or environmental pressure
7. **Collapse** — Phoenix Protocol (reincarnation)
8. **Renaissance** — New civilization emerges from ashes

This is **not a game**. This is a **scientific instrument** for studying emergent complexity.
