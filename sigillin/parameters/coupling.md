## Abstract

This document describes the **coupling parameter κ (kappa)**, a dimensionless quantity representing the fraction of information integration mediated by electromagnetic (photonic) processes. The κ-parameter extends the v_RIG framework to accommodate non-photonic information processing regimes, enabling comparative analysis of biological, artificial, and collective consciousness systems.

**Core Definition:**
```
κ = I_photonic / I_total

Where:
- I_photonic: Information integrated via electromagnetic coupling
- I_total: Total integrated information in the system
```
