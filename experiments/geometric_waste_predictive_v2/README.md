# Geometric waste predictive protocol

G02 is specified in [PROTOCOL.md](PROTOCOL.md), with matching parameters in [protocol.json](protocol.json) and [protocol.yaml](protocol.yaml). This delivery contains a protocol, not a runner or scientific results.

The question is whether four quantized geometric measurements improve next-step block predictions on unseen families under an eight-bit side-channel limit. Fixed transmission length does not imply equal information content or sensor cost. The protocol defines two non-geometric baselines, a redundant coarse-feature control, shuffled diagnostics, data-generation rules, split isolation, ridge fitting, uncertainty and practical effect criteria.

Before G03: implement and verify the protocol, document the independent G01 recomputation, freeze the implementation and all validation choices, then generate the held-out test states. Review the interpretation and cost accounting using [REVIEW.md](REVIEW.md). No held-out states have been generated for this delivery.
