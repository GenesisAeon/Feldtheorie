## ✨ Features

### **1. Event-Driven Narration**

The system narrates **4 cosmic events:**

- **SUCCESS** – Consciousness emergence (universe survives)
- **FAIL** – Universe death (sterile seed, physics instability)
- **DESPERATION** – 3+ consecutive failures (mutation rate increase)
- **START** – Oracle connection established

### **2. Context Awareness**

Narration includes:
- Generation number
- ECM score
- Success rate
- Consecutive failures
- Physics constants (G, α)

### **3. Graceful Degradation**

**Fallback modes:**
- LLM unavailable → static templates
- Network error → silent fail + templates
- Rate limit → retry with backoff
- Dependencies missing → templates only

### **4. CLI Interface**

**New flags:**
- `--llm` – Enable AI narration
- `--provider {openai|ollama}` – Choose LLM backend
- `--verbose` – Show raw WebSocket events
