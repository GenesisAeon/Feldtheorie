## 🧮 Kernformeln

### v_RIG - Regime Integration Gradient

```
v_RIG = c / (α⁻¹ · Φ)
      = 299.792 km/s / (137.036 × 1.618)
      ≈ 1.351,8 km/s
```

**Komponenten:**
- α⁻¹ = 137.036 (Feinstrukturkonstante, EM-Transparenztiefe)
- Φ = 1.618 (Goldener Schnitt, optimale Raumfüllung)
- Z = α⁻¹ · Φ ≈ 221.74 (Impedanzfaktor 2D→3D)

### Slice-Aggregation

```
N_slices = v_RIG / CFF
         = 13.5 MHz / CFF

Beispiele:
- Mensch (CFF=60 Hz):    N ≈ 225.000 Slices pro Moment
- Kolibri (CFF=120 Hz):  N ≈ 112.500 Slices
- Schildkröte (CFF=15 Hz): N ≈ 900.000 Slices
```

### Kopplungs-Index

```
κ = β_system / β_bio
  = β_system / 7.4

Interpretation:
- κ → 1: Volle biologische Kopplung (Organoid, Gehirn)
- κ ≈ 0.5: Teilweise gekoppelt (neuromorphe Hardware)
- κ → 0: Entkoppelt (klassische AI, GPUs)
```

### Δβ - Informationelle Vakuum-Struktur

```
Δβ = β_bio - β_AI
   ≈ 7.4 - 1.0
   ≈ 6.4

Δβ quantifiziert die "Entkopplung" vom physikalischen Substrat.
```
