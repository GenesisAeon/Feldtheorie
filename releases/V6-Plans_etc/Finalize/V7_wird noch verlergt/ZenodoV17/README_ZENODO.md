1. **Dual Entropy Governance**
   - Surface Regime (SCA): S ∝ A, governed by light speed *c*
   - Volume Regime (SCV): S ∝ V, governed by integration velocity *v_RIG*

2. **Impedance Factor Z**
   - Z = α⁻¹ · Φ ≈ 221.74
   - Represents the "resistance" to dimensional conversion

3. **Integration Velocity v_RIG**
   - v_RIG = c/Z ≈ 1,351.8 km/s
   - Universal constant for complex system integration

4. **β-Parameter**
   - Measures transition steepness in threshold systems
   - Clusters by domain (climate ≈11, biology ≈7.4, cognition ≈4.5)
