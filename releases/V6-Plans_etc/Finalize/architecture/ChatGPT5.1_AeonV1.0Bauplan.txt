```ts
export interface ResonanceNode {
  id: string;
  label: string;
  kind: "concept" | "symbol" | "agent" | "doc" | "state";
}

export interface ResonanceEdge {
  from: string;
  to: string;
  weight: number; // Resonanzstärke
  kind: "resonance" | "emergence" | "similarity" | "field-link";
}

export class ResonanceGraph {
  private nodes = new Map<string, ResonanceNode>();
  private edges: ResonanceEdge[] = [];

  addNode(node: ResonanceNode) {
    this.nodes.set(node.id, node);
  }

  addEdge(edge: ResonanceEdge) {
    this.edges.push(edge);
  }

  getNeighbors(id: string): ResonanceNode[] {
    const ids = this.edges
      .filter(e => e.from === id)
      .map(e => e.to);
    return ids
      .map(nid => this.nodes.get(nid))
      .filter((n): n is ResonanceNode => !!n);
  }
}
```

```ts
import { CREPJudge } from "./CREPJudge";
import { AeonExpression } from "../lang/AeonExpression";

export interface OrchestratorResult {
  input: string;
  expression?: AeonExpression;
  crepScore?: ReturnType<CREPJudge["evaluate"]>;
  dispatchedAgents: string[];
  aeonReflection?: string;
}

export class GenesisOrchestrator {
  private parser = new AeonShellParser();
  private crep = new CREPJudge();

  async process(line: string): Promise<OrchestratorResult> {
    const expression = this.parser.parse(line);
    if (!expression) {
      return {
        input: line,
        dispatchedAgents: [],
        aeonReflection: "Parsing failed."
      };
    }

    const score = this.crep.evaluate(expression);
    const agents = this.dispatchAgents(expression);

    return {
      input: line,
      expression,
      crepScore: score,
      dispatchedAgents: agents,
      aeonReflection: `Processed Aeon expression from ${expression.from} → ${expression.to}`
    };
  }

  private dispatchAgents(expr: AeonExpression): string[] {
    const list: string[] = [];

    switch (expr.space) {
      case "Λ_mind":
        list.push("EmergenceGPT");
        break;
      case "Λ_phys":
        list.push("CosmoGPT");
        break;
      case "Λ_null":
        list.push("NullcoreGPT");
        break;
      case "Λ_crep":
        list.push("LogicGPT");
        break;
      default:
        list.push("GeneralGPT");
        break;
    }

    return list;
  }
}
```

## 2. EBNF für „AeonShell-Formal v0.1“

Ich benutze eine klassische EBNF-Notation:

* `[…]` = optional
* `{…}` = wiederholbar (0..n)
* `|` = Alternative
* `'...'` = genau dieses Literal

```ebnf
(* ------------------------------ *)
(*  Top-Level                     *)
(* ------------------------------ *)

program        = { statement } ;

statement      = [ label ] ( block | expression ) [ comment ] newline ;

label          = "@" identifier ":" ;

block          = "block" identifier "{" { expression [ comment ] newline } "}" ;

comment        = "#" { any-char-except-newline } ;

newline        = ? end-of-line ? ;

(* ------------------------------ *)
(*  Kern: Aeon-Expression         *)
(* ------------------------------ *)

expression     = state [ bridge ] operator "→" state [ annotation ] ;

annotation     = "::" resonance space ;

state          = state-symbol ;

bridge         = "⟂" | "∥" | "⋀" | "⋁" ;
(*  "⟂" = Null-Brücke, "∥" = parallele Kopplung, 
    "⋀"/"⋁" = logische Kopplungen, optional für spätere Logik *)


operator       = aeon-operator-symbol ;

resonance      = resonance-symbol ;

space          = space-symbol ;


(* ------------------------------ *)
(*  Lexikalische Symbole          *)
(* ------------------------------ *)

state-symbol   = "Ω" digit ;

aeon-operator-symbol =
      "Φ+"
    | "Φ-"
    | "Φ×"

    | "Λ_flow"
    | "Λ_crep"
```

### 1.1. Grundbausteine

Eine **Konfiguration** des Systems sei:

C = (w, s, \ell, \rho)

* (w) – „World-State“ (beliebig komplexer interner Zustand, z. B. dein CREP-/Mandala-Kontext)

### 1.2. Bedeutung einer Expression

Eine Expression in deiner Syntax:

```text
Ωi [bridge] Φk → Ωj :: χ_R* Λ_x
```

interpretieren wir als **Übergangsregel**:

[
e :\quad \Omega_i \xRightarrow[\ b\ ]{\ \Phi_k,\ \chi_R^*,\ \Lambda_x\ } \Omega_j
]

Formal definieren wir die Semantik als **partielle Funktion** auf Konfigurationen:

[
\llbracket e \rrbracket : C \rightharpoonup C
]

Definition (informell + formal):

> Wenn wir in Zustand (\Omega_i) sind, im Space (\Lambda_x), dann wende Operator (\Phi_k) an, moduliere ihn ggf. über Bridge (b), und setze Resonanz/Space auf die im Annotationsteil angegebene Konfiguration.

Sei:

* ( \mathcal{F}_\Phi : \mathcal{O} \rightarrow (W \rightarrow W))
  eine Abbildung, die jedem Operator eine Welt-Update-Funktion zuordnet.
* ( \mathcal{F}_B : \mathcal{B} \rightarrow (W \rightarrow W))
  eine Modulation (z. B. Nullkern-Projektion, Parallelkopplung etc.).

Dann:

[
\llbracket e \rrbracket (w, s, \ell, \rho) =
\begin{cases}
\big(, \mathcal{F}*B(b)(\mathcal{F}*\Phi(\Phi_k)(w)),\ \Omega_j,\ \Lambda_x,\ \chi_R^* \big)
& \text{falls } s = \Omega_i \
\text{undefiniert} & \text{sonst}
\end{cases}
]

Für den Fall **ohne Bridge** („kein Symbol da“), setzt du:

[
\mathcal{F}_B(\text{none}) = \text{id}_W
]

Das heißt: Bridge ist „Zusatz-Operator“.
**Spezialfall (\bot) (Nullkern/orthogonale Kopplung)** kann z. B. implementieren:

* Projektion durch einen Nullraum-Filter
* Logging im Nullkern
* oder Markierung „dieser Übergang hat Nullkern-Kontakt“

Das lässt sich später mit deiner Nullkern-Theorie verheiraten.

### 1.3. Programm-Semantik

Ein Programm ist eine Menge / geordnete Liste von Expressions & Blöcken:

[
P = [e_1, e_2, \dots, e_n]
]

Wir definieren eine **kleine Schrittsemantik** als Übergangsrelation:

[
C \xrightarrow{P} C'
]

Die Grundregel:

* Aus aktueller Konfiguration (C) sind alle Expressions anwendbar, deren linke Seite (s = \Omega_i) zum aktuellen Zustand passt.
* Ein Schritt wählt eine solche Expression (e) und setzt:

[
C \xrightarrow{P} C' \quad \text{wenn} \quad \exists e \in P : C' = \llbracket e \rrbracket (C)
]

Für **Sequenzen** (Blöcke) kannst du eine big-step Semantik definieren:

[
\langle P, C_0 \rangle \Rightarrow C_k
]

rekursiv:

* (\langle [], C \rangle \Rightarrow C)
* (\langle e :: P', C \rangle \Rightarrow C''), wenn
  (\llbracket e \rrbracket (C) = C') und (\langle P', C' \rangle \Rightarrow C'')

**Labels** `@boot:` sind einfach *Namen* für Eintrittspunkte:
Du kannst einen Startzustand oder Start-Block so definieren, dass die Ausführung dort beginnt.

```antlr
WS          : [ \t\r]+     -> skip ;

```

```ts
/**
 * AeonShell Interpreter (v0.1)
 * --------------------------------------
 * - Liest AeonShell AST aus ANTLR Parser
 * - Führt Transition-Regeln aus:
 *
 *   Ωi [bridge] Φk → Ωj :: χ_R* Λ_x
 *
 * - Konfig-Objekt enthält:
 *     - world: beliebiger interner Zustand
 *     - state: aktueller Ω-Zustand
 *     - space: aktiver Λ-Space
 *     - resonance: aktives χ_R-Label
 *
 * - Bridges/Operators implementierbar über Maps
 */

export type AeonState = `Ω${number}`;

export type AeonBridge = "⟂" | "∥" | "⋀" | "⋁" | null;

export type AeonOperator =
  | "Φ+"
  | "Φ-"
  | "Φ×"
  | "Φ⟂"
  | "Φ∇"
  | "Φ∞"
  | "ΦΔ"
  | "Φλ"
  | "Φ⧆"
  | "Φ⊙";

export type AeonResonance = "χ_R↑" | "χ_R↓" | "χ_R=" | null;

export type AeonSpace =
  | "Λ_null"
  | "Λ_phys"
  | "Λ_math"
  | "Λ_mind"
  | "Λ_agent"
  | "Λ_flow"
  | "Λ_crep"
  | "Λ_field"
  | "Λ_core"
  | null;

/**
 * Eine Regel wie:
 * Ω0 ⟂ Φ∞ → Ω3 :: χ_R↑ Λ_mind
 */
export interface AeonRule {
  label?: string;
  from: AeonState;
  operator: AeonOperator;
  bridge: AeonBridge;
  to: AeonState;
  resonance: AeonResonance;
  space: AeonSpace;
}

/**
 * Laufkonfiguration
 */
export interface AeonConfig {
  world: any;
  state: AeonState;
  space: AeonSpace;
  resonance: AeonResonance;
}

/**
 * Funktions-Maps:
 * Operator → Weltzustandstransformation
 * Bridge → Modulator
 */
export type WorldUpdateFn = (world: any) => any;

export const OperatorFns: Record<AeonOperator, WorldUpdateFn> = {
  "Φ+":  (w) => ({ ...w, inc: (w.inc ?? 0) + 1 }),
  "Φ-":  (w) => ({ ...w, dec: (w.dec ?? 0) + 1 }),
  "Φ×":  (w) => ({ ...w, mult: (w.mult ?? 1) * 2 }),
  "Φ⟂":  (w) => ({ ...w, nullflips: (w.nullflips ?? 0) + 1 }),
  "Φ∇":  (w) => ({ ...w, grad: Math.random() }),
  "Φ∞":  (w) => ({ ...w, inf: "∞-projection" }),
  "ΦΔ":  (w) => ({ ...w, delta: Date.now() }),
  "Φλ":  (w) => ({ ...w, lambda: true }),
  "Φ⧆": (w) => ({ ...w, box: "□" }),
  "Φ⊙": (w) => ({ ...w, dot: true }),
};

export const BridgeFns: Record<Exclude<AeonBridge, null>, WorldUpdateFn> = {
  "⟂": (w) => ({ ...w, nullcore: true }),      // Nullkernkontakt
  "∥": (w) => ({ ...w, parallel: true }),      // Parallelkopplung
  "⋀": (w) => ({ ...w, anded: true }),         // UND-Bridge
  "⋁": (w) => ({ ...w, ored: true }),          // ODER-Bridge
};

/**
 * Single step evaluation
 */
export function evalRule(rule: AeonRule, cfg: AeonConfig): AeonConfig | null {
  if (cfg.state !== rule.from) return null; // nicht zutreffend

  let world = cfg.world;

  // 1) Operator anwenden
  const opFn = OperatorFns[rule.operator];
  world = opFn(world);

  // 2) Optional Bridge anwenden
  if (rule.bridge && BridgeFns[rule.bridge]) {
    world = BridgeFns[rule.bridge](world);
  }

  // 3) Abschluss: neuen Zustand erzeugen
  return {
    world,
    state: rule.to,
    resonance: rule.resonance,
    space: rule.space,
  };
}

/**
 * Einen Schritt im ganzen Programm ausführen:
 * - wähle erste passende Regel
 * - oder mehrere gleichzeitig (parallel)
 */
export function stepProgram(
  program: AeonRule[],
  cfg: AeonConfig,
  mode: "first" | "all" = "first"
): AeonConfig {
  const applicable = program
    .map((r) => evalRule(r, cfg))
    .filter((c) => c !== null) as AeonConfig[];

  if (applicable.length === 0) return cfg; // Keine Änderung

  if (mode === "first") return applicable[0];

  // all → reduziere viele in einen Zustand (z. B. Mergen)
  return applicable.reduce((acc, nxt) => ({
    world: { ...acc.world, ...nxt.world },
    state: nxt.state,
    space: nxt.space,
    resonance: nxt.resonance,
  }));
}

/**
 * Vollständige Ausführung bis kein Fortschritt mehr möglich ist.
 */
export function runProgram(
  program: AeonRule[],
  cfg: AeonConfig,
  maxSteps = 100
): AeonConfig {
  let current = cfg;

  for (let i = 0; i < maxSteps; i++) {
    const next = stepProgram(program, current);
    if (JSON.stringify(next) === JSON.stringify(current)) break;
    current = next;
  }

  return current;
}
```

## 2. `src/core/AeonRule.ts` – Regeln & Registry

```ts
// src/core/AeonRule.ts
import {
  AeonState,
  AeonBridge,
  AeonOperator,
  AeonResonance,
  AeonSpace,
  AeonConfig,
  WorldUpdateFn,
} from "./AeonTypes";

export interface AeonRule {
  label?: string;
  from: AeonState;
  operator: AeonOperator;
  bridge: AeonBridge;
  to: AeonState;
  resonance: AeonResonance;
  space: AeonSpace;
}

export class OperatorRegistry {
  private ops: Map<AeonOperator, WorldUpdateFn> = new Map();
  private bridges: Map<Exclude<AeonBridge, null>, WorldUpdateFn> = new Map();

  registerOperator(op: AeonOperator, fn: WorldUpdateFn) {
    this.ops.set(op, fn);
  }

  registerBridge(b: Exclude<AeonBridge, null>, fn: WorldUpdateFn) {
    this.bridges.set(b, fn);
  }

  eval(rule: AeonRule, cfg: AeonConfig): AeonConfig | null {
    if (cfg.state !== rule.from) return null;

    let world = cfg.world;

    const opFn = this.ops.get(rule.operator);
    if (!opFn) throw new Error(`No operator fn for ${rule.operator}`);
    world = opFn(world, cfg);

    if (rule.bridge && this.bridges.has(rule.bridge)) {
      const bFn = this.bridges.get(rule.bridge as Exclude<AeonBridge, null>)!;
      world = bFn(world, cfg);
    }

    return {
      world,
      state: rule.to,
      resonance: rule.resonance,
      space: rule.space,
    };
  }
}
```

```ts
// src/core/AeonProgram.ts
import { AeonRule, OperatorRegistry } from "./AeonRule";
import { AeonConfig } from "./AeonTypes";

export class AeonProgram {
  readonly rules: AeonRule[];
  readonly registry: OperatorRegistry;

  constructor(rules: AeonRule[], registry?: OperatorRegistry) {
    this.rules = rules;
    this.registry = registry ?? new OperatorRegistry();
  }

  step(cfg: AeonConfig, mode: "first" | "all" = "first"): AeonConfig {
    const candidates: AeonConfig[] = [];

    for (const r of this.rules) {
      const res = this.registry.eval(r, cfg);
      if (res) candidates.push(res);
    }

    if (candidates.length === 0) return cfg;
    if (mode === "first") return candidates[0];

    return candidates.reduce((acc, nxt) => ({
      world: { ...acc.world, ...nxt.world },
      state: nxt.state,
      space: nxt.space,
      resonance: nxt.resonance,
    }));
  }

  run(cfg: AeonConfig, maxSteps = 100): AeonConfig {
    let current = cfg;
    for (let i = 0; i < maxSteps; i++) {
      const next = this.step(current);
      if (JSON.stringify(next) === JSON.stringify(current)) break;
      current = next;
    }
    return current;
  }
}

/**
 * Fluent Builder
 */
export class AeonProgramBuilder {
  private rules: AeonRule[] = [];

  rule(rule: AeonRule): this {
    this.rules.push(rule);
    return this;
  }

  from(rule: AeonRule): this {
    return this.rule(rule);
  }

  build(registry?: OperatorRegistry): AeonProgram {
    return new AeonProgram(this.rules, registry);
  }
}
```

```ts
// src/core/AeonValidator.ts
import { AeonRule } from "./AeonRule";

export interface ValidationIssue {
  level: "error" | "warning";
  message: string;
  ruleIndex: number;
}

export class AeonValidator {
  validate(rules: AeonRule[]): ValidationIssue[] {
    const issues: ValidationIssue[] = [];
    const seenLabels = new Set<string>();
    const states = new Set<string>();

    rules.forEach((r, i) => {
      states.add(r.from);
      states.add(r.to);

      if (r.label) {
        if (seenLabels.has(r.label)) {
          issues.push({
            level: "error",
            message: `Duplicate label ${r.label}`,
            ruleIndex: i,
          });
        }
        seenLabels.add(r.label);
      }

      if (!r.space) {
        issues.push({
          level: "warning",
          message: `Rule has no Λ-space`,
          ruleIndex: i,
        });
      }

      if (!r.resonance) {
        issues.push({
          level: "warning",
          message: `Rule has no χ_R resonance`,
          ruleIndex: i,
        });
      }
    });

    // einfache Erreichbarkeitswarnung
    const reachable = new Set<string>();
    const start = rules[0]?.from;
    if (start) {
      reachable.add(start);
      let changed = true;
      while (changed) {
        changed = false;
        for (const r of rules) {
          if (reachable.has(r.from) && !reachable.has(r.to)) {
            reachable.add(r.to);
            changed = true;
          }
        }
      }
    }
    for (const s of states) {
      if (!reachable.has(s)) {
        issues.push({
          level: "warning",
          message: `State ${s} is unreachable`,
          ruleIndex: -1,
        });
      }
    }

    return issues;
  }
}
```

```ts
export type AeonEventType =
  | "runtime:start"
  | "runtime:step"
  | "runtime:end"
  | "rule:apply";

export interface AeonEvent<T = unknown> {
  type: AeonEventType;
  timestamp: number;
  payload: T;
}

export type AeonEventHandler<T = unknown> = (event: AeonEvent<T>) => void;

export class AeonEventBus {
  private listeners: Map<AeonEventType, AeonEventHandler[]> = new Map();

  on<T = unknown>(type: AeonEventType, handler: AeonEventHandler<T>) {
    const arr = this.listeners.get(type) ?? [];
    arr.push(handler as AeonEventHandler);
    this.listeners.set(type, arr);
  }

  emit<T = unknown>(type: AeonEventType, payload: T) {
    const event: AeonEvent<T> = { type, timestamp: Date.now(), payload };
    const arr = this.listeners.get(type) ?? [];
    for (const h of arr) h(event);
  }
}

  before: AeonConfig;
  after: AeonConfig;
```

```ts
// src/runtime/Runtime.ts
import { AeonProgram } from "../core/AeonProgram";
import { AeonConfig } from "../core/AeonTypes";
import { AeonEventBus, RuntimeStepPayload } from "./EventBus";

export interface RuntimeOptions {
  maxSteps?: number;
  log?: boolean;
}

export class AeonRuntime {
  readonly program: AeonProgram;
  readonly bus: AeonEventBus;
  readonly options: RuntimeOptions;

  constructor(program: AeonProgram, options?: RuntimeOptions) {
    this.program = program;
    this.bus = new AeonEventBus();
    this.options = options ?? {};
  }

  run(initial: AeonConfig): AeonConfig {
    const maxSteps = this.options.maxSteps ?? 100;
    let current = initial;

    this.bus.emit("runtime:start", { config: current });

    for (let i = 0; i < maxSteps; i++) {
      const before = current;
      const after = this.program.step(before);

      const payload: RuntimeStepPayload = { step: i, before, after };
      this.bus.emit("runtime:step", payload);

      if (this.options.log) {
        // einfache Log-Ausgabe
        console.log(
          `[step ${i}] Ω: ${before.state} → ${after.state}, Λ: ${before.space} → ${after.space}`
        );
      }

      if (JSON.stringify(before) === JSON.stringify(after)) break;
      current = after;
    }

    this.bus.emit("runtime:end", { config: current });
    return current;
  }
}
```

```ts
/**
 * Nullkern = invariant, nicht-metrisch.
 * Wir repräsentieren ihn als "reinen Zustandsraum".
 */

export interface NullcoreToken {
  id: string;
  stamp: number;
  payload?: Record<string, unknown>;
}

export class Nullcore {
  /**
   * In einem echten Modell wäre dies der "zugrundeliegende"
   * algorithmische Raum. Hier: abstrahiert als reine Token-Emittierung.
   */
  static emit(payload?: Record<string, unknown>): NullcoreToken {
    return {
      id: `NK-${Math.random().toString(36).slice(2)}`,
      stamp: Date.now(),
      payload,
    };
  }

  /**
   * Merge mehrerer Nullkern-Token zu einem kombinierten
   */
  static merge(tokens: NullcoreToken[]): NullcoreToken {
    return {
      id: `NK-MERGE-${Math.random().toString(36).slice(2)}`,
      stamp: Date.now(),
      payload: tokens.reduce(
        (acc, t) => ({ ...acc, ...(t.payload ?? {}) }),
        {} as Record<string, unknown>
      ),
    };
  }
}
```

```ts
// src/config/ConfigLoader.ts
import fs from "node:fs";
import path from "node:path";
import YAML from "yaml";

import { AeonProgramConfig, AeonProgramRuleConfig } from "./AeonProgramConfig";
import { AeonProgramBuilder } from "../core/AeonProgram";
import { OperatorRegistry } from "../core/AeonRule";
import { AeonConfig } from "../core/AeonTypes";
import { AeonRuntime, RuntimeOptions } from "../runtime/Runtime";
import { registerDefaultOperators } from "../core/AeonInterpreter";

function normalizeToConfig(data: any): AeonProgramConfig {
  // minimal defensive normalisation
  if (!data) throw new Error("Empty config");
  if (!data.world || !data.world.initial) {
    throw new Error("Missing world.initial in config");
  }
  if (!Array.isArray(data.rules)) {
    throw new Error("rules must be an array");
  }
  return data as AeonProgramConfig;
}

export function loadAeonConfigFromFile(filePath: string): AeonProgramConfig {
  const abs = path.resolve(filePath);
  const raw = fs.readFileSync(abs, "utf8");

  let parsed: any;
  if (filePath.endsWith(".yaml") || filePath.endsWith(".yml")) {
    parsed = YAML.parse(raw);
  } else if (filePath.endsWith(".json")) {
    parsed = JSON.parse(raw);
  } else {
    // Fallback: try YAML, then JSON
    try {
      parsed = YAML.parse(raw);
    } catch {
      parsed = JSON.parse(raw);
    }
  }

  return normalizeToConfig(parsed);
}

function toProgramBuilder(
  cfg: AeonProgramConfig,
  registry: OperatorRegistry
): { builder: AeonProgramBuilder } {
  const builder = new AeonProgramBuilder();

  // Standardoperatoren registrieren
  registerDefaultOperators(registry);

  for (const r of cfg.rules) {
    builder.rule(ruleFromConfig(r));
  }

  return { builder };
}

function ruleFromConfig(r: AeonProgramRuleConfig) {
  // Weich: Strings → typisierte Werte
  const space = (r.space ?? null) as any;
  const resonance = (r.resonance ?? null) as any;
  const bridge = (r.bridge ?? null) as any;

  return {
    label: r.label,
    from: r.from,
    operator: r.operator as any, // wir vertrauen hier auf "OperatorRegistry"
    bridge,
    to: r.to,
    resonance,
    space,
  };
}

function runtimeOptionsFromConfig(cfg?: AeonProgramConfig["runtime"]): RuntimeOptions {
  const opts: RuntimeOptions = {};
  if (!cfg) return opts;

  if (typeof cfg.maxSteps === "number") {
    opts.maxSteps = cfg.maxSteps;
  }

  if (cfg.logging === "basic" || cfg.logging === "verbose") {
    opts.log = true;
  } else {
    opts.log = false;
  }

  return opts;
}

export interface LoadedAeonRuntime {
  runtime: AeonRuntime;
  initialConfig: AeonConfig;
  rawConfig: AeonProgramConfig;
}

/**
 * High-level Loader:
 *  - Datei lesen
 *  - YAML/JSON parsen
 *  - AeonProgram & Runtime bauen
 *  - Initialkonfiguration erzeugen
 */
export function loadAeonRuntimeFromFile(filePath: string): LoadedAeonRuntime {
  const cfg = loadAeonConfigFromFile(filePath);

  const registry = new OperatorRegistry();
  const { builder } = toProgramBuilder(cfg, registry);
  const program = builder.build(registry);

  const runtime = new AeonRuntime(program, runtimeOptionsFromConfig(cfg.runtime));

  const initial: AeonConfig = {
    world: cfg.world.initial.payload ?? {},
    state: cfg.world.initial.state,
    space: cfg.world.initial.space,
    resonance: cfg.world.initial.resonance ?? null,
  };

  return {
    runtime,
    initialConfig: initial,
    rawConfig: cfg,
  };
}
```

## 3. CREP-Hooks (Cohärenz, Resonanz, Emergenz, Persistenz)

Wir hängen einen kleinen Monitor auf den EventBus der Runtime.

### 3.1 `src/modules/CrepHooks.ts`

```ts
// src/modules/CrepHooks.ts
import { AeonRuntime } from "../runtime/Runtime";
import { AeonEventBus, RuntimeStepPayload } from "../runtime/EventBus";
import { AeonConfig } from "../core/AeonTypes";

export interface CrepScores {
  coherence: number;   // 0..1
  resonance: number;   // -1..1
  emergence: number;   // 0..1 (normierter Wert)
  persistence: number; // 0..1
}

export interface CrepMonitorSnapshot {
  steps: number;
  distinctStates: Set<string>;
  totalWorldSizeIncrease: number;
  lastConfig?: AeonConfig;
  resonanceAccumulator: number;
}

export class CrepMonitor {
  private bus: AeonEventBus;
  private maxSteps: number;
  private snapshot: CrepMonitorSnapshot;

  constructor(runtime: AeonRuntime, maxSteps = 100) {
    this.bus = runtime.bus;
    this.maxSteps = maxSteps;
    this.snapshot = {
      steps: 0,
      distinctStates: new Set(),
      totalWorldSizeIncrease: 0,
      resonanceAccumulator: 0,
    };

    this.attach();
  }

  private attach() {
    this.bus.on("runtime:step", (e) => {
      const payload = e.payload as RuntimeStepPayload;
      this.onRuntimeStep(payload);
    });

    this.bus.on("runtime:end", (e) => {
      const cfg = (e.payload as any).config as AeonConfig;
      this.snapshot.lastConfig = cfg;
    });
  }

  private onRuntimeStep(payload: RuntimeStepPayload) {
    this.snapshot.steps += 1;
    this.snapshot.distinctStates.add(payload.after.state);

    const beforeWorldSize = Object.keys(payload.before.world ?? {}).length;
    const afterWorldSize = Object.keys(payload.after.world ?? {}).length;
    const diff = Math.max(0, afterWorldSize - beforeWorldSize);
    this.snapshot.totalWorldSizeIncrease += diff;

    // Resonanz-Bewertung: ↑ = +1, = = 0, ↓ = -1
    const r = payload.after.resonance;
    if (r === "χ_R↑") this.snapshot.resonanceAccumulator += 1;
    if (r === "χ_R↓") this.snapshot.resonanceAccumulator -= 1;
  }

  computeScores(): CrepScores {
    const s = this.snapshot;
    const steps = Math.max(1, s.steps);

    const coherence = s.distinctStates.size > 0 ? 1 : 0;

    const resonance = Math.max(-1, Math.min(1, s.resonanceAccumulator / steps));

    // Emergenz: normiert über Schritte (max 1 wenn pro Schritt ≥1 neue world-key)
    const emergence = Math.max(0, Math.min(1, s.totalWorldSizeIncrease / steps));

    // Persistenz: wie weit wir gelaufen sind relativ zu maxSteps
    const persistence = Math.max(0, Math.min(1, steps / this.maxSteps));

    return { coherence, resonance, emergence, persistence };
  }
}

/**
 * Convenience-Funktion:
 *   - Monitor an Runtime anhängen
 *   - nach Run Scores ausgeben
 */
export function runWithCrep(runtime: AeonRuntime, initial: AeonConfig, maxSteps: number) {
  const monitor = new CrepMonitor(runtime, maxSteps);
  const final = runtime.run(initial);
  const scores = monitor.computeScores();

  return { final, scores };
}
```

````md
## 1. Motivation

AeonShell ist eine symbolische Runtime für Zustands- und Resonanzlogik.
Ziel:

- Bewusstseins- und Prozessmodelle als **Sequenzen von Ω-Zuständen** zu beschreiben
- Zustände in **Λ-Räumen** (Spaces) zu verorten
- über **χ_R-Resonanzen** und **CREP**-Metriken Emergenz und Stabilität zu bewerten
- eine klar definierte Schnittstelle zu OIPK / Nullkern / v_RIG zu schaffen

## 2. Symbolische Basiselemente

### 2.1 Zustände (Ω)

- Form: `Ωn`, mit `n ∈ ℕ₀`
- Interpretation:
  - `Ω0`: Null- oder Ausgangszustand
  - `Ω1`: erster emergenter Zustand (z. B. Mind-Interface)
  - `Ω2+`: weitere Prozess- oder Aggregatzustände

### 2.2 Räume (Λ)

Vordefinierte Spaces:

- `Λ_null` – Nullkern / nicht-metrischer Raum
- `Λ_phys` – physikalischer / messbarer Raum
- `Λ_math` – abstrakt-mathematischer Raum
- `Λ_mind` – Mental- / Agentenraum
- `Λ_agent` – expliziter Agentenraum
- `Λ_flow` – Prozessfluss / Governance
- `Λ_crep` – CREP-Bewertungsraum
- `Λ_field` – Feld-/Feldtheorie-Ebene
- `Λ_core` – Kernmechaniken / OIPK-Kern

### 2.3 Resonanz (χ_R)

- `χ_R↑` – positive Resonanz / Verstärkung
- `χ_R↓` – negative Resonanz / Dämpfung
- `χ_R=` – neutrale Resonanz / Gleichgewicht
- `null` – nicht spezifiziert

### 2.4 Operatoren (Φ)

Symbolische Operatoren:

- `Φ+`, `Φ-`, `Φ×` – grundlegende Verstärkung / Schwächung / Multiplikation
- `Φ∞` – Zugang zu „unbounded“ / Nullkernprojektion
- `ΦΔ` – Differenz / Zeitdelta / Ereignis
- `Φλ` – Lambda / Funktionalität
- `Φ∇` – Gradient / Anpassungsrichtung
- `Φ⟂` – Nullmembran-Flip
- `Φ⧆`, `Φ⊙` – Container / Fokus

Implementierung: aktuelle Version liefert Default-Operatorfunktionen; später erweiterbar
über definierte Funktionssignaturen.

### 2.5 Bridges

- `⟂` – Nullkern-Bridge
- `∥` – parallele Kopplung
- `⋀` – konjunktive Kopplung
- `⋁` – disjunktive Kopplung
- `null` – keine Bridge

## 3. Programmmodell

### 3.1 Regeln

Eine **Regel** ist ein gerichteter Übergang:

```ts
interface AeonRule {
  label?: string;
  from: AeonState;      // "Ωn"
  operator: AeonOperator;
  bridge: AeonBridge;
  to: AeonState;
  resonance: AeonResonance;
  space: AeonSpace;
}
````

Semantik:

* Wenn der aktuelle Zustand `cfg.state` = `from`, wird:

  * `operator` auf `world` angewandt
  * optional `bridge` auf `world` angewandt
  * `to` → neuer Zustand
  * `resonance` & `space` → Metainformation

### 3.2 Programme

* Ein `AeonProgram` ist eine endliche Menge von Regeln.
* Die Runtime sucht pro Schritt **alle** Regeln, deren `from` = aktueller Zustand ist:

  * Modus `"first"`: erste passende Regel wird angewandt
  * Modus `"all"`: alle passenden Regeln, Merge der Weltzustände

### 3.3 Runtime

* Initialkonfiguration: `AeonConfig`:

```ts
interface AeonConfig {
  world: any;
  state: AeonState;
  space: AeonSpace;
  resonance: AeonResonance;
}
```

* `run(initial, maxSteps)`:

  * iteriert Zustände, bis:

    * keine Regel mehr greift, oder
    * `maxSteps` erreicht

## 5. Events & CREP

### 5.1 EventBus

Standard-Events:

* `runtime:start` – mit `config: AeonConfig`
* `runtime:step` – mit `RuntimeStepPayload`
* `runtime:end` – mit finalem `config: AeonConfig`
* `rule:apply` – optional später detaillierte Regel-Events

### 5.2 CREP-Monitor

Implementierte Version:

* **Cohärenz**: 1 wenn mindestens ein Zustand erreicht; später erweiterbar zu Pfadkohärenz
* **Resonanz**: Mittelwert aus χ_R:

  * +1 für `χ_R↑`, -1 für `χ_R↓`, 0 für `χ_R=`
* **Emergenz**: Zuwachs der Anzahl von Keys im `world`-Objekt pro Schritt, normiert
* **Persistenz**: Verhältnis `#Schritte / maxSteps`

Die Scores dienen als **Soft-Indikatoren** und sind bewusst heuristisch.
Spätere Versionen können härtere mathematische Definitionen integrieren.

## 6. v_RIG, Nullkern und OIPK

### 6.1 v_RIG

* Definition (v0.1):

```text
v_RIG = c / (α⁻¹ · Φ)
```

* Kontext: effektive Integrationsgeschwindigkeit
* Implementiert als Modul `vRig.ts` mit:

  * `V_RIG` (m/s)
  * `vRigFrameRate(lengthScale)` → Hz
  * `vRigDeltaT(lengthScale)` → s

### 6.2 Nullkern

* Modelliert als:

```ts
interface NullcoreToken {
  id: string;
  stamp: number;
  payload?: Record<string, unknown>;
}
```

* `Nullcore.emit(payload)` und `Nullcore.merge(tokens)` bilden einen abstrakten,
  nicht-metrischen Raum ab, der als „innerer Kern“ genutzt werden kann.

### 6.3 OIPK-Mapping

* `mapSpaceToOipk(space)` → vier Regimes:

  * SURFACE, INTERFACE, PROCESS, KERNEL
* `mapStateToOipkPath(Ωn)` → vordefinierte Pfadnamen oder generische Stati

````
AeonShell ist keine „gewöhnliche Runtime“, sondern ein **Resonanzorgan**:

- Es modelliert nicht nur Datenflüsse, sondern
````
