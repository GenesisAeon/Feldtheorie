## Reproducibility Statement

All experiments reproducible via:
```bash
# Install dependencies
pip install -r requirements.txt

# Run full v9 stack
python v9_alpha/main_simulation.py \
  --enable-solar-driver \
  --enable-resonator \
  --enable-reaper \
  --enable-sensorium \
  --output-prefix results/living_crystal_run

# Run Oracle experiment
python v9_alpha/main_simulation.py \
  --experiment oracle \
  --oracle-steps 200 \
  --output-prefix results/oracle_run
```

Expected runtime: 10-30 minutes on standard laptop (CPU-only).
