KEY FINDINGS FROM PAPER
================================================================================

POWER-LAW EXPONENTS:
• αN = 0.076  → Loss scaling with model size (parameters)
• αD = 0.095  → Loss scaling with dataset size (tokens)
• αC = 0.057  → Loss scaling with compute (PF-days)
• αB = 0.21   → Critical batch size scaling
• αS = 0.76   → Training steps scaling

LOSS SCALING FORMULA:
L(X) ∝ 1/X^αX

Where X can be:
- N (number of parameters)
- D (dataset size in tokens)
- C (compute in PF-days)

KEY INSIGHT:
"Universality of training: Training curves follow predictable power-laws whose 
parameters are roughly independent of model architecture."
