## 🎯 THE CORE EQUATION

```
        1
S(R) = ─────────────────
       1 + e^(-β(R - Θ))
```

**Where:**
- `R` = System Progress (stress, complexity, temperature)
- `Θ` = Critical Threshold
- `β` = **STEEPNESS** (the key metric!)
- `S(R)` = System Response (0 to 1)
