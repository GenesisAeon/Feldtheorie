## 🌌 What is the Narrative Track?

The UTAC project operates on **two parallel tracks**:

1. **Scientific Track** (`../science/`) - Empirical research, mathematical models, statistical validation
2. **Narrative Track** (this directory) - Interpretive frameworks, philosophical context, developmental story

This separation allows:
- **Scientists** to focus on falsifiable hypotheses without cognitive overhead
- **Philosophers** to explore meaning, ethics, and long-term implications
- **Both** to inform each other without conflation

## 📖 Core Concepts

### Trilayer System (Sigillin)

Every central information exists in **three synchronized forms**:
1. **YAML** - Agent-readable configuration
2. **JSON** - Machine-parsable data
3. **Markdown** - Human-readable narrative

See [Sigillin](sigillin/) for implementation details.

### Agent Collaboration

The project embraces **multi-agent development** with distinct roles:
- **Researcher** - Empirical analysis & validation
- **Architect** - System design & integration
- **Poet** - Narrative coherence & meaning-making
- **Guardian** - Ethical oversight & safety

See [AGENTS.md](docs/AGENTS.md) for the full charter.

### Philosophical Themes

- **Threshold Thinking** - Phase transitions as universal pattern
- **Emergence** - How complexity arises from simple rules
- **Integration** - Bridging disciplines (physics, AI, climate, consciousness)
- **Responsibility** - Ethical implications of threshold models

## 🌱 Seed Directory

The `seed/` directory contains:
- **Early Explorations** - Initial ideas, speculative models
- **Failed Experiments** - What didn't work (and why)
- **Conceptual Roots** - Inspirations from physics, philosophy, AI
- **Session Logs** - Developmental journey of key insights

**Philosophy:** We preserve the **full intellectual journey**, not just polished results. Science benefits from transparency about dead ends and pivots.

---

## 📜 Releases Directory

The `releases/` directory contains:
- **Version Narratives** - Philosophical reflections per release
- **Integration Stories** - How new concepts were woven in
- **Community Reflections** - Feedback & dialogue

Each release (v1.0, v2.0, ..., v10.2) has a narrative companion explaining:
- What changed conceptually (not just code)
- Why those changes matter
- What questions they open
