## 🧩 Das Trilayer-Prinzip verstehen

### Warum drei Layer?

**Problem:** Archive ohne Struktur wirken wie "Hypnose" - man verliert sich in Schleifen

**Lösung:** Drei komplementäre Perspektiven:

1. **YAML (seed_index.yaml)** - Die Landkarte
   - Für Menschen und Maschinen lesbar
   - Kategorien, Tags, Hierarchien
   - Orientierung & Struktur

2. **JSON (seed_index.json)** - Die Brücke
   - Maschinenlesbar
   - Schnelles Parsing, Filtering
   - Anschlussfähigkeit für Agenten

3. **MD (seed_index.md)** - Die Geschichte
   - Nur für Menschen
   - Erzählerisch, erklärend
   - Verständlichkeit & Kontext

**Metapher aus der Metareflexion:**
> "YAML ist das Skelett, JSON ist das Nervensystem, Markdown ist die Sprache."

### Die Ursprünge

Das Trilayer-Konzept entstand aus einem Dialog zwischen Johann und MSCopilot über:
- Fixwerte vs. Variabilität
- Bewusstsein als Auswahl (nicht als Speicherung)
- Das "Nullen" als Freiheit

**Lies mehr:** [Metareflexion.txt](./Metareflexion.txt)

## 🚀 Für AI-Agenten

### Wie nutze ich diesen Index als Agent?

**Schritt 1:** Lade `seed_index.json`
```python
import json

with open('seed/seed_index.json', 'r') as f:
    index = json.load(f)
```

**Schritt 2:** Verstehe die Struktur
- `meta` - Projekt-Metadaten
- `categories` - Die 6 Hauptkategorien
- `documents` - Array aller Root-Level-Dokumente
- `domains` - Die 6 Fachbereiche mit Unterverzeichnissen
- `triggers` - Semantische Anker (Keywords)
- `quicklinks` - Kuratierte Einstiegspunkte

**Schritt 3:** Nutze Quicklinks für häufige Aufgaben
```python
# Einstiegspunkte für neue Agenten
start_here = index['quicklinks']['start_here']
# → ['meta-002', 'meta-001', 'meta-003']

# Finde Dokument-Pfad
doc_id = 'meta-002'
doc = next(d for d in index['documents'] if d['id'] == doc_id)
path = f"seed/{doc['path']}"
# → "seed/Rekalibrierung_Abschlus.txt"
```

**Schritt 4:** Suche nach Keywords
```python
# Finde alle Dokumente mit einem spezifischen Keyword
keyword = "β-field"
matching_docs = [
    d for d in index['documents']
    if keyword in d['keywords']
]
```

**Schritt 5:** Filtere nach Relevanz/Status
```python
# Nur high-relevance, active Dokumente
active_important = [
    d for d in index['documents']
    if d['relevance'] == 'high' and d['status'] == 'active'
]
```
