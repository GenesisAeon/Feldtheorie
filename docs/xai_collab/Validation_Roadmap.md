# Validation Roadmap (12 Weeks)

## Month 1 — Foundation (Weeks 1–4)

- **Week 1:** finalize datasets, schema checks, and governance boundaries.
- **Week 2:** baseline scaling pilot run on small grid; verify persistence and reproducibility.
- **Week 3:** enable distributed sweep mode and benchmark throughput.
- **Week 4 Milestone:** β/σ_Φ landscape generated for initial dataset cohort.

## Month 2 — Safety Integration (Weeks 5–8)

- **Week 5:** integrate `AFETSafetyMonitor` in training hooks.
- **Week 6:** run controlled instability injections for threshold tests.
- **Week 7:** Aeon compatibility pass and telemetry alignment.
- **Week 8 Milestone:** validated shutdown path for σ_Φ < 0.055.

## Month 3 — Product Prototypes (Weeks 9–12)

- **Week 9:** climate loader integration and signal quality checks.
- **Week 10:** dashboard snapshot + drift flags in near-real-time loop.
- **Week 11:** HfO₂ interface review with hardware partners.
- **Week 12 Milestone:** handover package (code, docs, validation report).

## Success Metrics

- Sweep completion reliability > 99% on defined grid jobs.
- Safety monitor triggers correctly in all injected critical scenarios.
- Climate prototype reports warning/critical counts without schema errors.
- Interface contract accepted for joint hardware planning.
