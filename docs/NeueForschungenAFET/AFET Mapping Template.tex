\section{AFET Mapping Matrix: Domains, System Types, and Band Mechanisms}

\subsection{Purpose and Usage}
This table operationalizes AFET as a \emph{mechanism framework} rather than a single closed-form law.
For each domain $d$ and system type $t$, we register:
(i) what is measured, (ii) how entropy production is proxied,
(iii) where threshold dynamics appear, and (iv) which parameters are \emph{bands} (ranges/distributions) rather than constants.

\paragraph{Core UTAC/AFET structure.}
We use the baseline activation form:
\begin{equation}
A(t)=\sigma\!\left(\beta_{\mathrm{eff}}(t)\left(R(t)-\Theta_{\mathrm{eff}}(t)\right)\right),
\quad
\sigma(x)=\frac{1}{1+e^{-x}}.
\end{equation}
AFET asserts that entropy production (or a dissipation proxy) modulates the effective parameters:
\begin{equation}
(\beta_{\mathrm{eff}},\Theta_{\mathrm{eff}},\zeta_{\mathrm{eff}})=\mathcal{F}_{d,t}\!\left(\Pi_d, \nabla \Pi_d, J_d, \kappa_{\text{int}}, \kappa_{\text{ext}}, \ldots \right),
\end{equation}
where $\Pi_d$ is the domain-specific entropy production proxy, $J_d$ an energy/entropy flux proxy, and $\kappa$ coupling measures.

\paragraph{Band-in-band principle.}
Instead of constants, we treat parameters as hierarchical bands:
\begin{equation}
\beta_{d,t,i}(t)=\mu_d + \delta_{d,t} + \delta_{d,t,i} + g_{d,t}\!\left(\Pi_{d,t,i}(t)\right) + \varepsilon,
\end{equation}
and analogously for $\Theta$ and $\zeta$ where appropriate.

\subsection{Optional: Parameter Band Sheet (per domain/type)}
For each domain/type entry above, maintain a band sheet:
\begin{equation}
\beta_{d,t} \sim \mathcal{D}_{d,t}(\mu_{d,t}, \sigma_{d,t}, \text{skew}, \text{kurt}),
\quad
\Theta_{d,t} \sim \mathcal{T}_{d,t}(\cdot),
\quad
\zeta_{d,t} \sim \mathcal{Z}_{d,t}(\cdot).
\end{equation}
Recommended metadata per band:
\begin{itemize}
\item Estimation method (fit / literature / bound / simulation)
\item Measurement scale (micro/meso/macro)
\item Coarse-graining notes (hidden $\Pi$, loss of time-reversal odd variables)
\item Known counterexamples / boundary conditions
\end{itemize}

\subsection{Minimal Must-Fail Tests (to prevent over-flexibility)}
To avoid an ``entropy explains everything'' failure mode, each row must include at least one must-fail test:
\begin{enumerate}
\item \textbf{Null coupling test:} vary $\Pi_d$ proxy while holding other controls fixed; if $\beta,\Theta,\zeta$ remain unchanged, AFET coupling for that domain/type is invalid.
\item \textbf{Equilibrium boundary test:} if the domain has an equilibrium limit, verify AFET reduces to a statement about \emph{where it does not apply} (e.g., criticality at $\Pi=0$).
\item \textbf{Coarse-graining test:} confirm observed $\Pi$ decreases under coarse-graining (or justify exceptions) and track hidden dissipation.
\end{enumerate}
